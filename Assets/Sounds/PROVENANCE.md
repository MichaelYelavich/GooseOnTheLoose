# Sound sources

Honk1–4.mp3, BITE.mp3, and MudSquith.mp3 come from the original Desktop Goose assets preserved in [elliotgsy/DesktopGooseDecompiled](https://github.com/elliotgsy/DesktopGooseDecompiled/tree/0b01b89c5fdecce07f9156398861564d7500cc22/bin/Debug/Assets/Sound/NotEmbedded).

Pat1–3.wav are the original Desktop Goose footstep samples preserved in [RealEmmettS/goose](https://github.com/RealEmmettS/goose/tree/eeefcfe1b9e09c21528fbea2b43dbec58a281455/Assets/Sounds).

The sequel uses these samples to retain Desktop Goose's sound. The runtime loads them through Windows audio APIs. It does not run either reference project's executable.
