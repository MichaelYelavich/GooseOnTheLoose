# Roadmap

Beta feedback determines priorities; these are directions, not promised dates.

## Next: personality and play

- More distinct habits, reactions, and interactions between the two geese.
- Richer interactions with existing toys and water before expanding the toy count.
- More expressive, readable procedural animation and accessible reduced-motion behavior.
- Continued performance measurements, stress tests, and fixes from reproducible bug reports.

## Then: multiple displays

- Movement across displays and sensible object/window placement.
- Mixed-DPI scaling, negative display coordinates, display disconnect/reconnect, and sleep/resume.
- A dedicated hardware test matrix before changing the current selected-display model.

## Later exploration

Content collections, better organization, and additional documented behavior presets. A scripted mod API, automatic updater, or mandatory dashboard is not part of Beta Release 1.
